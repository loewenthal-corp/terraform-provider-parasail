# parasail Provider

Unofficial Terraform and OpenTofu provider for [Parasail](https://www.parasail.io/) dedicated model deployments. It is a community project, not affiliated with or endorsed by Parasail, and uses only Parasail's public Control API.

The provider manages [dedicated deployments](https://docs.parasail.io/), which serve a
Hugging Face model on GPUs reserved for your account. Each deployment exposes an
OpenAI-compatible endpoint: send requests to its `base_url` with `model` set to its
`model_alias`.

## Authentication

Create an API key in the Parasail dashboard and either export it:

```shell
export PARASAIL_API_KEY="..."
```

or pass it as `api_key`, ideally from a sensitive variable as in the example below.
The `api_key` argument takes precedence over the environment variable.

## Choosing GPUs

Parasail's GPU catalog changes over time and differs per model. Rather than
hard-coding GPU types, look them up with
[`parasail_dedicated_device_configs`](data-sources/dedicated_device_configs.md), which
returns each configuration's price and current availability.

## Example Usage

```terraform
terraform {
  required_version = ">= 1.6.0"

  required_providers {
    parasail = {
      source  = "registry.terraform.io/loewenthal-corp/parasail"
      version = ">= 0.2.0"
    }
  }
}

provider "parasail" {
  api_key = var.parasail_api_key
}

variable "parasail_api_key" {
  type      = string
  sensitive = true
}
```

### Optional

- `api_key` (String, Sensitive) Parasail API key. Can also be set with the `PARASAIL_API_KEY` environment variable; the provider argument takes precedence.
- `endpoint` (String) Parasail Control API base URL. Must be an absolute URL. Can also be set with `PARASAIL_ENDPOINT`. Defaults to `https://api.parasail.io/api/v1`.
- `operation_timeout_minutes` (Number) Maximum time to wait for a deployment to become `ONLINE` or to be deleted, in minutes. Defaults to `60`; values of 0 or less use the default.
- `poll_interval_seconds` (Number) How often to poll deployment status while waiting for `ONLINE` or for deletion, in seconds. Defaults to `30`; values of 0 or less use the default.
- `request_timeout_seconds` (Number) Timeout for each HTTP request, in seconds. Defaults to `60`; values of 0 or less use the default.
